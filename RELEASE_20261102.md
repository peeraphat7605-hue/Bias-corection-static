# Station results release — 2026-11-02

The site displays 98 ranked stations: 85 original payloads and 13 patch payloads. Patch results take precedence by station ID. There are 33 excluded stations: 32 exceed the 20% missing-data threshold; 459204 has unresolved station metadata.

## Provenance

- `data_provenance.json` records the source Drive URL and SHA-256 of every published JSON payload.
- `stations/*.json` preserve the exact source bytes. JavaScript wrappers enable loading without manual uploads.
- `catalog.json` indexes all 131 stations and links downloads to the applicable original or patch result.
- `ranking_station_map.csv` provides the current 98 mapped stations and the excluded records. Coordinates for ranked stations match their result payloads.
- Historical coverage CSV downloads are retained and labeled as the original coverage audit.

No source Drive files, QC criteria, rainfall values, metrics, or ranking orders were changed. This release is a presentation merge, not a rerun or validation of XGBoost.
